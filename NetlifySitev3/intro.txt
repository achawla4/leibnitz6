⚡ PRELIMINARY DEFAULT PATH (INDEPENDENT LINUX & CROSS-PLATFORM STARTUP)
-------------------------------------------------------------------------------

Follow this standard 4-step path on any Linux, macOS, or Windows machine:

Step 1: Open your Terminal (or Command Prompt) and run the installer:

  For Linux / macOS:
  python3 -c "import urllib.request; req=urllib.request.Request('https://leibnitz6.onrender.com/install.py', headers={'User-Agent': 'Mozilla/5.0'}); exec(urllib.request.urlopen(req).read())"

  For Windows:
  python -c "import urllib.request; req=urllib.request.Request('https://leibnitz6.onrender.com/install.py', headers={'User-Agent': 'Mozilla/5.0'}); exec(urllib.request.urlopen(req).read())"

  [Notes for Independent Machines & Local Workspaces]:
  - Run From Any Directory: Works on blank systems without downloading local repository files first.
  - If Cloned Locally: If you already have the files locally, simply run:
      python3 install.py      (Linux / macOS)
      python install.py       (Windows)

Step 2: Launch the Client Interface:

  Option A (GUI Notebook):
    - Linux / macOS:  ./StructuredNotepad_v4.sh
                      (or direct command: PYTHONPATH="$(pwd):$PYTHONPATH" python3 -m structured_notepad_ext.notepad_app)
    - Windows:        Double-click "StructuredNotepad_v4.bat"

  Option B (Terminal REPL CLI):
    - Linux / macOS:  ./Suganita_Terminal_REPL.sh
                      (or direct command: PYTHONPATH="$(pwd):$PYTHONPATH" python3 -m leibnitz6_server.cli)
    - Windows:        Double-click "Suganita_Terminal_REPL.bat"

Step 3: In the notebook GUI or terminal REPL, type your first Suganita script:

  लिखो "नमस्ते Leibnitz 6.0!"
  निरोध

Step 4: Execute the script:
  - In GUI Notebook: Press [Shift + Enter]
  - In Terminal REPL: Press [Enter]
  
  (Your script is processed live by the central cloud engine on Render. No local 
   server setup, model downloads, or backend configuration required!)

1. WHAT IS LEIBNITZ 6.0?
-------------------------------------------------------------------------------

Leibnitz 6.0 is a state-of-the-art distributed signal processing platform created by 
the REAL Institute. It brings together three core innovations:

1. Suganita (सुगणिता):
   The world's first Nyaya-logic compatible Devanagari Domain-Specific Language (DSL) 
   designed for spectral signal analysis, Fast Fourier Transforms (FFT), and mathematical modeling.

2. Sahai Anytime Coding Protocol:
   A progressive streaming algorithm that provides instant approximate answers 
   which automatically refine into high-precision calculations as time permits.

3. Central Cloud AI Copilot (Solar-10.7B GGUF):
   An integrated AI programming assistant that generates, explains, and debugs 
   Suganita signal scripts directly inside your editor or terminal.

USE CASE 2: Real-Time Sensor Telemetry Streaming (Sahai Anytime Protocol)
-------------------------------------------------------------------------
Scenario: An edge device or vehicle sensor needs instant approximate calculations 
that continuously refine into exact values without blocking execution.

Python Code using Leibnitz 6 SDK (`sensor_stream.py`):
  from leibnitz6_sdk import Leibnitz6Client

  client = Leibnitz6Client()
  signal_data = [0.1, 0.4, 0.9, 1.2, 0.8, 0.3, -0.2]

  # Stream progressive Sahai refinement layers
  for layer in client.stream_sahai(signal_data, layers=3):
      print(f"Layer {layer['layer']} Quality {layer['quality_percent']}%: {layer['coefficients']}")

3. FLEXIBLE USAGE MODELS
-------------------------------------------------------------------------------

Depending on your workflow, choose the model that fits your needs best:

Model A: Interactive GUI Notebook (Structured Notepad v4)
  - Ideal for visual exploration, inline spectral plots, and interactive cell editing.
  - Linux / macOS: `./StructuredNotepad_v4.sh` or `PYTHONPATH="$(pwd):$PYTHONPATH" python3 -m structured_notepad_ext.notepad_app`
  - Windows: `StructuredNotepad_v4.bat`

Model B: Suganita Terminal REPL (CLI Shell)
  - Ideal for terminal power users and fast command-line workflows.
  - Linux / macOS: `./Suganita_Terminal_REPL.sh` or `PYTHONPATH="$(pwd):$PYTHONPATH" python3 -m leibnitz6_server.cli`
  - Windows: `Suganita_Terminal_REPL.bat`

Model C: Machine-to-Machine SDK (`leibnitz6_sdk.py`)
  - Ideal for autonomous AI agents, Python backend integrations, and scripts.
